# PR #142 代码审查任务计划

## 目标

对 GitHub PR #142 的当前精确 head 执行只读代码审查，对照关联 Issue、HL-Spec、Module Spec、Module Test、实际实现与测试证据，给出可复现、可定位、与合并相关的审查结论。

## 执行步骤与成功标准

1. 建立精确基线：读取 PR head/base、关联 Issue、CI、变更文件和当前工作区状态；确认审查对象未在过程中漂移。
2. 权威合同审查：读取相关 HL-Spec、Module Spec/Test 和修复验证记录，逐项映射 PR 声明与关闭条件。
3. 实现与测试审查：检查实际 diff、调用链和持久化/跨模块边界；为关键不变量构造直接负例，不以绿色测试替代语义证明。
4. 验证：执行聚焦测试、必要的直接探针和与风险相称的仓库门禁；将外部、生产和人工边界准确保留为 `NOT RUN`。
5. 结论：形成带文件位置、严重级别、影响和最小修复要求的代码审查记录；只在证据充分时发布 GitHub review。

## 权限边界

- 本次仅授权代码审查和只读验证。
- 不修改生产代码、权威 Spec/Test、Migration 或 Contract。
- 不执行 Git commit、push、merge、Issue closure 或分支清理。
- 本地审查文档不在用户确认前提交。
