# Historical Records

This directory preserves prior plans, published Issue drafts, verification reports, and delivery snapshots. Original content is retained with mechanical reference updates and provenance notices; old statuses and commands are not current execution instructions.

Use the [roadmap](../product/roadmap.md) for forward intent and GitHub Issue/PR for execution state. A historical label does not waive an unresolved technical constraint: reconcile it with the owning specification before changing behavior.

The [migration map](migration-map.csv) maps every moved source to its destination and immutable source revision hash. This is a one-time migration record, not a workflow state database.
