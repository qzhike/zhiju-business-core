# Review Records

Create new required pre-close review records at `pr-<number>/Review.md`. Record the exact reviewed revision, findings, verification evidence, and unrun boundaries. Preserve failed rounds; a later approval does not erase earlier results.

Existing records are preserved under `legacy/` with their original directory names. Find original paths in the [migration map](../archive/migration-map.csv). These records do not approve a different current head.
